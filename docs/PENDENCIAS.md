# O que falta do cliente

Antes de o site ir ao ar como site oficial (e não só como demonstração):

- [ ] **Logo final**: arquivo original limpo (sem marca d'água), em versões para fundo claro e escuro (PNG transparente ou SVG).
- [ ] **Projetos reais**: nomes, áreas, quartos, plantas e imagens; hoje são fictícios.
- [ ] **Preços e prazos reais** de cada pacote (Estrutura, Casa Fechada, Chave na Mão), ou a decisão de não mostrar preços.
- [ ] **O que cada pacote inclui**, confirmado pelo responsável técnico.
- [ ] **Contatos**: telefone, WhatsApp, e-mail, Instagram, Facebook, endereço e área de atendimento.
- [ ] **Empresa**: CNPJ, responsável técnico (com registro profissional) e história.
- [ ] **Garantias** e informações técnicas do Light Steel Frame (normas, isolamento, fechamentos).
- [ ] **Política de privacidade** para o formulário de contato.
- [ ] **Domínio**: confirmar disponibilidade no registro.br das opções da proposta (`lucernacasas.com.br`, `lucernachales.com.br`, `lucernaconstrutora.com.br`, `lucernaengenharia.com.br`) e a marca no INPI.
- [ ] **Fotos de obras reais**, quando houver, no lugar das imagens geradas por IA.
